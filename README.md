# Advanced Calculator 🧮

A modern, feature-rich calculator built with vanilla JavaScript, HTML, and CSS. Experience smooth interactions and powerful functionality with a sleek dark-themed interface.

## Features

✨ **Core Features**
- Basic arithmetic operations (addition, subtraction, multiplication, division)
- Decimal number support
- Clear and delete functionality
- Real-time display with sub-display for operations

🔧 **Advanced Functions**
- Square root (√)
- Square (x²)
- Reciprocal (1/x)
- Percentage calculations
- Negate (+/−)
- Pi (π) constant
- Error handling (e.g., division by zero)

💾 **Memory Operations**
- Memory Clear (MC)
- Memory Recall (MR)
- Memory Add (M+)
- Memory Subtract (M−)
- Memory indicator display

🎨 **Design**
- Modern dark theme with vibrant gradient accents
- Responsive design for mobile and desktop
- Smooth button animations and hover effects
- Color-coded buttons for different function types
- Professional typography and spacing

## How to Use

1. **Open** the calculator: Visit [https://ramoskimmich-hash.github.io](https://ramoskimmich-hash.github.io)
2. **Click** number buttons to enter values
3. **Select** an operator (+, −, ×, ÷)
4. **Press** equals (=) to calculate the result
5. **Use** advanced functions for complex calculations
6. **Utilize** memory buttons for storing intermediate results

## Button Guide

| Button Type | Color | Function |
|---|---|---|
| Numbers | Blue | Input digits 0-9 and decimal point |
| Operators | Red | +, −, ×, ÷ operations |
| Functions | Teal | √, x², %, 1/x, +/−, π |
| Equals | Green | Calculate final result |
| Mode | Purple | Switch calculation modes |
| Memory | Orange | Memory management (MC, MR, M+, M−) |
| Clear | Red | Clear all calculations |

## Installation for Development

1. Clone the repository:
```bash
git clone https://github.com/ramoskimmich-hash/ramoskimmich-hash.github.io.git
cd ramoskimmich-hash.github.io
```

2. Open `index.html` in your browser or use a local server:
```bash
python -m http.server 8000
# or
npx http-server
```

3. Visit `http://localhost:8000` in your browser
